# Лабораторна робота №5: Наука про дані: обмін результатами та початковий аналіз

## Огляд проекту
Цей проект є інтерактивним веб-додатком, розробленим за допомогою бібліотеки **Streamlit**. Основна мета — надати зручний інтерфейс для візуалізації та аналізу даних індексів стану вегетації (VCI, TCI, VHI), отриманих з NOAA під час виконання Лабораторної роботи №2.

## Реалізований функціонал (згідно з вимогами):
* **Інтерактивні фільтри:**
    * Випадаючий список для вибору часового ряду (VCI, TCI або VHI).
    * Випадаючий список для вибору області України для аналізу.
    * Слайдер для вибору інтервалу тижнів, за які відбираються дані.
    * Слайдер для вибору інтервалу років.
* **Керування станом:** Кнопка для скидання всіх фільтрів до початкових значень (інтерактивні елементи повертаються до початкових значень).
* **Сортування:** Два чекбокси для сортування даних за зростанням або спаданням значень VCI, TCI або VHI. Передбачено логіку обробки ситуації, коли обрані обидва варіанти.
* **Структура інтерфейсу:**
    * Використання колонок: фільтри розміщені в одній колонці, результати — у правій.
    * Використання трьох вкладок (Tabs) для відображення таблиці з відфільтрованими даними, відповідного графіка та графіка порівняння даних по областях.

## Вимоги до системи
* **Python**: версія 3.9 або вище.
* **Бібліотеки**: streamlit, pandas, plotly.
* **Дані**: наявність папки `vhi_data` з CSV-файлами у корені проекту.

## Структура репозиторію
* `app.py` — основний файл програми.
* `requirements.txt` — файл із переліком необхідних модулів.
* `README.md` — документація проекту.
* `vhi_data/` — каталог із вхідними даними.

## Інструкція з запуску

### 1. Створення віртуального середовища
`python -m venv venv`

### 2. Активація середовища
`source venv/Scripts/activate`

### 3. Встановлення залежностей
`pip install -r requirements.txt`

### 4. Запуск додатка
`streamlit run app.py`
