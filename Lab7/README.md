# Лабораторна робота №7 - Computer Vision та багатопотоковість у C++

Програма для захоплення відео з камери та обробки зображень у реальному часі. Реалізовано багатопотокову детекцію облич за допомогою Deep Neural Networks (dnn) на базі ResNet-10 та креативні візуальні ефекти.

## Вимоги до системи та обладнання
* **ОС**: Linux (Ubuntu 20.04/22.04 або сумісні) / WSL2 із прокинутою камерою.
* **Компілятор**: GCC/G++ з підтримкою C++17.
* **Система збірки**: CMake 3.10+.
* **Обладнання**: Підключена та налаштована веб-камера (пристрій `/dev/video0`).

## Керування режимами
Під час роботи програми натискайте наступні клавіші для зміни фільтрів:

* 1 — Нормальний режим
* 2 — Інверсія кольорів
* 3 — Glitch ефект (Розсування RGB каналів)
* 4 — Детекція облич (Виділення зеленою рамкою)
* 5 — Face Blur (Анонімізація/розмиття обличчя)
* ESC — Вийти з програми

## Реалізований функціонал
Захоплення відео: Безперервне зчитування та відображення відеопотоку з підключеної веб-камери у реальному часі.
Модульна архітектура: Проєкт побудовано з використанням об'єктноорієнтованого підходу. Логіку розділено на незалежні класи (CameraProvider, KeyProcessor, FrameProcessor, FaceDetector, Display) із винесенням оголошень у .hpp, а реалізацій — у .cpp файли.
Багатопотоковість: Детекцію облич винесено в окремий фоновий потік за допомогою std::thread та std::mutex, що забезпечує стабільний FPS відеопотоку під час інференсу важкої нейромережі.
Інтерактивність: Програма обробляє натискання клавіш клавіатури "на льоту" для перемикання режимів відображення.
Фільтри обробки (Computer Vision):
1. Нормальний режим: Відображення оригінального потоку.
2. Інверсія кольорів: Реалізована за допомогою функції bitwise_not.
3. Glitch: Зсув каналів R та B для створення ефекту спотворення.
4. Детекція облич: Асинхронний пошук обличчя за допомогою нейромережі ResNet-10.
5. Face Blur: Анонімізація знайденого обличчя за допомогою сильного розмиття.
6. Лічильник FPS: Динамічне обчислення та відображення кадрів на секунду на екрані.

## Інструкція зі збірки та запуску

Щоб зібрати та запустити проєкт з нуля, виконайте наступні команди у терміналі (у кореневій теці проєкту):

1. Встановлення залежностей (включає завантаження моделі нейромережі):
   ./preinstall.sh
2. Збірка проєкту:
   ./build.sh
3. Запуск:
   ./run.sh
